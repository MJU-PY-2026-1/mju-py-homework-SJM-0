## 🟩 [2차 과제: V1.0] 입출력 + 리스트 + 조건문 - 향후 작성 예정
### **✨2차 과제 내용:**
이번 2차 과제에서는 파이썬의 반복문(for)과 리스트, 그리고 다중 분기문(if-elif-else)을 도입하여 포스기 시스템을 고도화했습니다. 사용자가 주문할 음료의 수량을 입력하면, for문과 range()를 통해 수량만큼 메뉴 선택을 반복하며 주문 내역을 리스트(order_list)에 저장합니다. 이때 조건문을 활용해 메뉴별 단가를 판별하고 복합 대입 연산자(+=)로 총액을 누적합니다. 마지막으로 매장/포장 여부와 멤버십 유무를 묻는 중첩 조건문을 통해 최종 할인율을 적용하는 로직을 완성했습니다. 특히 사용자가 입력한 주문 수량을 다 채우지 않더라도 '0번'을 입력하면 break를 통해 즉시 결제 단계로 넘어가는 조기 종료 기능을 추가하여 사용자 편의성을 높였습니다.
  
### **🤖 AI 파트너십 과정**

1. **내용 1: 파이썬 반복문과 조건문의 결합 로직 설계 **
    * **프롬프트 요약:** "2차 과제 필수 조건으로 'for문, 리스트, 다중 조건문, += 연산자'를 써야 해. 내가 만든 카페 포스기에서 여러 잔의 음료를 한 번에 주문받는 방식으로 이 조건들을 자연스럽게 엮어줄 수 있을까?"
    * **적용 내용:** AI의 제안에 따라 주문할 음료 수량을 먼저 입력받고, for i in range(수량) 형태로 반복문을 구성함. 반복문 내부에 if-elif-else를 넣어 메뉴를 판별하고, 선택된 메뉴는 리스트에 추가하며 가격은 += 연산자로 누적 합산하는 최적의 흐름을 구현함.

2. **내용 2: 복합 대입 연산자 초기화 오류 해결**
    * **프롬프트 요약:** "코드에서 total_price += price를 썼더니 NameError: name 'total_price' is not defined라는 에러가 나. 이거 왜 이러는 거고 어떻게 고쳐야 해?"
    * **적용 내용:** += 연산자는 기존 변수 값에 새로운 값을 더하는 것이므로, 반복문이 시작되기 전에 반드시 total_price = 0으로 초기화를 해주어야 한다는 AI의 조언을 듣고 코드를 수정하여 에러를 완벽히 해결함.
    
### **🛠️ Troubleshooting & 기술 회고:**

1. **문제 1: 메뉴 가격을 합산하기 위해 += 연산자를 사용했을 떄 NameError 발생.**
    * **원인:** for 반복문 안에서 total_price += price 구문을 실행하려 했으나, 반복문 진입 전에 total_price라는 변수가 아예 생성(초기화)되어 있지 않아 컴퓨터가 어떤 값에 가격을 더해야 할지 몰라 에러를 발생시킴.
    * **해결:** 반복문(for)이 시작되기 바로 윗줄에 total_price = 0이라는 초기값을 선언해 줌으로써, 0원부터 정상적으로 메뉴 가격이 누적 합산되도록 문제를 해결함.
